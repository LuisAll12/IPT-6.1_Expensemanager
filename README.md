# IPT-6.1_Expensemanager
Das Ziel des Expensemanagers, ist es uns den Umgang und die Budgetierung mit Geld zu vereinfachen. Es ist nicht nur möglich Budgets für selbstbestimmte Kategorien auszuwählen, sondern auch alle gewünschten Transaktionen zu erfassen und mit den gesetzten Budgets abzugleichen.

- [SQLite](https://www.sqlite.org/)
- [GitLab](https://gitlab.com/)

## Installation

Diesen Befehl im gewünschten Zielrepository ausführen.
```bash
git clone git@gitlab.com:LuisAll12/ipt-6.1_expensemanager.git
```


Anschliessend [Expensesmanager.exe](Projekt\Expensesmanager\Expensesmanager\obj\Debug\Expensesmanager.exe) unter diesem Pfad öffnen.
